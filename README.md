## Generation

Read the latest published frostmage1250/mihomo-script/main/mihomoScript.js once,
extract its active configuration once, translate to native Egern fields, then
publish Profile.yaml. The source model exists only in the runner's temporary
directory. It is independently extracted, not shared by the converter.

Native rule bodies are published by proxy-rules-converter/egern. Read its small
source/filename index once and require matching provider URLs, behaviors and
formats before publication. Historical rules/*.yaml in this repository remain
frozen compatibility URLs and are not used by the generated profile.

### DNS and real-IP exceptions

- Keep separate `dns.private_dns` groups for Doro (one DoH endpoint) and MESL
  (two DoH endpoints). Match the eight server hostnames from the supplied Doro
  subscription exactly, and match MESL server domains under `911-gt2-rs.com`.
  Put these DNS forwarding rules before the ordinary traffic DNS policies.
- Omit `proxy_nameservers` so proxy DNS uses the domain-based Forward rules.
  Force connections to the private DNS endpoints through DIRECT to avoid a
  dependency on a proxy that still needs its server hostname resolved.
- These rules match queried domains, not subscription identities, and also apply
  to ordinary DNS queries for the same names. IP-literal nodes need no DNS.
  Update the manifest if a subscription introduces different server domains.
- Restore the three Flower hostname aliases. Route `aws-agent.biz` and
  `apt-agent.com` through the MESL resolver group using `dns.forward_prepend`,
  preserving the DNS servers used by Flower before the subscription DNS split.
  Both the original server names and their alias targets need explicit matches.
- Let Egern Bootstrap resolve encrypted DNS server hostnames; do not synthesize
  `system` Forward entries for those names from the endpoint DIRECT routes.
- Exclude MCDN blocking hosts via `dns.hosts_exclude_suffixes`:
  mcdn.bilivideo.com, mcdn.bilivideo.cn, edge.mountaintoys.cn and h2.smtcdns.net,
  including their wildcard/subdomain mappings. Apply this exclusion on every
  generation; MCDN blocking continues through the existing REJECT rule set.
- Merge the 15 retained Egern real-IP exceptions with literal source Fake-IP
  exceptions, without duplicates. This affects DNS answers, not routing policy.

- Enable `dns.direct_domain_system_dns`: each fixed DIRECT domain rule and
  domain rule set gets a matching `system` DNS forwarding entry. Generate these
  entries from the final routes on every build, through the last fixed DIRECT
  domain rule. Preserve earlier proxy domain exceptions (including APNs,
  AppleTV and Apple Podcasts) as Foreign DNS entries in the same order.
  IP-only routes and exact domains already pinned to IP addresses in hosts do
  not create DNS forwarding entries.
- Set `dns.system_dns_providers: ["cn"]`: the inherited cn DNS policy also
  uses system DNS instead of its source resolver addresses.
- Append remaining source DNS policies without duplicate matchers, then retain
  the final `* -> Foreign` fallback. Egern cannot reproduce Mihomo's
  direct-nameserver re-resolution, so explicit forwarding entries are required.

## Native adaptation

Source group order, visibility, service routing and supported parameters
are preserved subject to the explicit manifest aliases, removed groups and extra
groups and disabled services. Icons are omitted when icons.enabled is false. select stays select; load-balance becomes
native load_balance. With latency tests disabled, no latency-driven groups or
latency-test parameters are published.

Egern has no native Mihomo direct-proxy variants: their candidates map to DIRECT.
Unsupported REJECT-DROP/PASS group choices are omitted; the source rule actions
are otherwise unchanged. The AdBlock group retains REJECT. PROCESS-NAME rules
are omitted because Egern on iOS exposes no process matcher. Emby is excluded
by the manifest, including its domain rules. Dynamic flattening does not preserve every nested group as a
selectable item. Mihomo-only group fields lazy, max-failed-times, empty-fallback,
default-selected and exclude-type have no exact native equivalent and are omitted.

DNS endpoint routing suffixes and base hosts come from the source. Bootstrap
uses source startup IPs as plain UDP because Egern bootstrap accepts only UDP IPs.
Mihomo +. hosts become an apex mapping plus a *. wildcard mapping.
Rule-set-based fake-ip-filter and direct-nameserver re-resolution have no exact
equivalent in this static native profile.

The workflow performs one generation and its integrated structural/reference
validation before publishing. No local tests, model artifact, or extra test stage
is required.
